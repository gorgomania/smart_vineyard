# Smart Vineyard

Веб-приложение для управления виноградниками с AI-классификацией состояния кустов.

## Возможности

- **Карта виноградников** — добавление и редактирование виноградников через интерактивную карту (Яндекс Карты)
- **Структура рядов и кустов** — автоматическая генерация рядов и кустов по заданным параметрам
- **Медиатека** — загрузка фото и видео, организация по папкам, привязка к конкретным кустам
- **AI-классификация** — анализ состояния куста по фотографии (чёрная гниль, эска, листовой ожог, здоровый) с помощью ONNX-модели
- **Статистика** — сводка по состоянию виноградника с диаграммами
- **Фоновые задачи** — обработка ZIP-архивов, генерация превью, распределение медиа по кустам через Solid Queue

## Стек

- **Ruby on Rails 8** + PostgreSQL + PostGIS
- **Devise** — аутентификация
- **Pundit** — авторизация
- **Solid Queue / Solid Cache / Solid Cable** — очереди, кэш, WebSocket
- **ActiveStorage** — хранение медиафайлов
- **ONNX Runtime** + Numo::NArray — инференс AI-модели
- **Hotwire** (Turbo + Stimulus) + TailwindCSS 4

## Требования

- Ruby 3.3+
- PostgreSQL с расширением PostGIS
- FFmpeg (для превью видео)
- libvips (для обработки изображений)
- Redis

## Фоновые задачи

Solid Queue запускается автоматически через `bin/dev`. Очереди:
- `default` — основные задачи (генерация кустов, классификация, загрузка медиа)
- `low_priority` — превью изображений и видео, нормализация имён файлов

## AI-классификация

> Скрипты обучения, конвертации и тестирования, информация о датасете и обученных моделях: **[grape-disease-classifier](https://gitverse.ru/gorgomania/grape-disease-classifier)**

Модель (`grape_model.onnx`) основана на архитектуре **EfficientNet-B0**, обученной на датасете болезней виноградных листьев. Запускается локально через ONNX Runtime без обращения к внешним API.

**Предобработка изображения:**
- Ресайз с сохранением пропорций и центральная обрезка до 224×224
- Нормализация по ImageNet (mean `[0.485, 0.456, 0.406]`, std `[0.229, 0.224, 0.225]`)
- Входной тензор: `[1, 3, 224, 224]` (NCHW)

**Классы:**

| ID | Название                     |
|----|------------------------------|
| 0  | Чёрная гниль (Black Rot)     |
| 1  | Эска (ESCA)                  |
| 2  | Здоровый (Healthy)           |
| 3  | Листовой ожог (Leaf Blight)  |

Для каждого изображения возвращается предсказанный класс, уверенность и вероятности по всем классам.

**Метрики на тестовой выборке (3 610 изображений):**

| Класс                        | Precision  | Recall     | F1-score   | Изображений |
|------------------------------|------------|------------|------------|-------------|
| Чёрная гниль (Black Rot)     | 99.68%     | 99.58%     | 99.63%     | 944         |
| Эска (ESCA)                  | 99.69%     | 99.79%     | 99.74%     | 960         |
| Здоровый (Healthy)           | 99.65%     | 99.76%     | 99.70%     | 846         |
| Листовой ожог (Leaf Blight)  | 99.77%     | 99.65%     | 99.71%     | 860         |
| **Итого**                    | **99.70%** | **99.70%** | **99.70%** | **3 610**   |

└── Vineyard (виноградник)

    │       └── MediaItem (фото/видео с AI-классификацией)
    └── Folder (папка с медиафайлами)
        └── MediaItem
